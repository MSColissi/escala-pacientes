# Sistema de Avaliação por Escalas Clínicas

Sistema web desenvolvido como parte de um **projeto de pesquisa de Mestrado** da **Universidade Federal de Santa Maria (UFSM)**, com o objetivo de disponibilizar uma ferramenta para aplicação de escalas clínicas utilizadas na avaliação de pacientes em ambiente hospitalar.

O sistema busca facilitar a utilização das escalas por profissionais da saúde, reduzindo erros de cálculo, padronizando as avaliações e registrando o histórico das aplicações.

---

## 📚 Sobre o Projeto

As escalas clínicas são amplamente utilizadas para avaliação da condição do paciente, tomada de decisão clínica e acompanhamento da evolução durante a internação.

Este projeto reúne diversas escalas em uma única plataforma, permitindo:

- Aplicação rápida das escalas;
- Cálculo automático da pontuação;
- Interpretação dos resultados;
- Registro das avaliações realizadas;
- Interface intuitiva para utilização em dispositivos desktop e móveis.

O desenvolvimento faz parte de uma pesquisa de **Mestrado da Universidade Federal de Santa Maria (UFSM)**, buscando contribuir para a informatização e padronização da aplicação dessas ferramentas no contexto assistencial.

---

## 🩺 Escalas Disponíveis

Atualmente o sistema contempla as seguintes escalas:

### Escala de Coma de Glasgow
Avalia o nível de consciência do paciente através das respostas:

- Resposta ocular
- Resposta verbal
- Resposta motora

Com cálculo automático da pontuação total.

---

### Escala de Braden
Avalia o risco de desenvolvimento de lesão por pressão considerando fatores como:

- Percepção sensorial
- Umidade
- Atividade
- Mobilidade
- Nutrição
- Fricção e cisalhamento

---

### Código Morse
Utilizada para avaliação do risco de quedas em pacientes hospitalizados.

Considera critérios como:

- Histórico de quedas
- Diagnóstico secundário
- Auxílio para deambulação
- Terapia intravenosa
- Marcha
- Estado mental

---

### Escala de Fugulin
Ferramenta para classificação da complexidade assistencial do paciente, auxiliando no dimensionamento da equipe de enfermagem.

---

### Escala de Dor
Permite registrar a intensidade da dor relatada pelo paciente, auxiliando no acompanhamento clínico e na tomada de decisão terapêutica.

---

### Escala de Fragilidade (FRAIL)
Instrumento utilizado para identificação da síndrome da fragilidade, principalmente em pacientes idosos.

## 🖥️ Tecnologias Utilizadas

O sistema foi desenvolvido utilizando tecnologias modernas do ecossistema JavaScript/TypeScript, priorizando desempenho, escalabilidade e uma interface responsiva.

### Front-end

- **React 19** — Construção da interface de usuário.
- **TypeScript** — Tipagem estática para maior confiabilidade e manutenção do código.
- **Vite** — Ferramenta de desenvolvimento e build de alta performance.
- **React Router DOM** — Gerenciamento de rotas da aplicação.

### Interface e Estilização

- **Tailwind CSS v4** — Framework utilitário para estilização.
- **shadcn/ui** — Biblioteca de componentes acessíveis baseada em Radix UI.
- **Radix UI** — Componentes primitivos acessíveis e altamente customizáveis.
- **Lucide React** — Biblioteca de ícones.
- **Inter Variable Font** — Tipografia otimizada para interfaces modernas.
- **Class Variance Authority (CVA)** — Gerenciamento de variantes de componentes.
- **clsx** — Composição condicional de classes CSS.
- **tailwind-merge** — Mesclagem inteligente de classes do Tailwind.
- **tw-animate-css** — Utilitários para animações com Tailwind CSS.
- **Vaul** — Componentes para drawers responsivos.
- **Sonner** — Sistema de notificações (toasts).

### Progressive Web App (PWA)

- **Vite Plugin PWA** — Suporte à instalação da aplicação como Progressive Web App (PWA), permitindo melhor experiência em dispositivos móveis e possibilidade de funcionamento offline em cenários compatíveis.

### Qualidade de Código

- **Oxlint** — Linter para análise estática e padronização do código.
- **TypeScript Compiler (tsc)** — Verificação de tipos durante o processo de build.

### Deploy

- **GitHub Pages** — Publicação da aplicação utilizando o pacote **gh-pages**.
